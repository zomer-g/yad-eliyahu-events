# אירועים ביד אליהו · Yad Eliyahu Arena Events

אתר שמרכז את כל האירועים הצפויים ב**היכל מנורה מבטחים (יד אליהו), תל אביב**: הופעות, משחקי כדורסל, מופעים וכנסים. לכל אירוע מוצגת הערכה של גודל הקהל ושל שעות העומס באזור, כדי לתכנן מראש מתי להגיע הביתה.

- **אתר מותאם לנייד** (אפשר גם להוסיף למסך הבית).
- **תצוגות רשימה, שבוע וחודש**, עם צביעת ימים לפי רמת העומס.
- **סנכרון לגוגל קלנדר** (בעמוד ה-API) דרך פיד iCal שמתעדכן אוטומטית, עם סינון לפי סוג ואפשרות להוסיף גם את חלונות העומס (הגעה ויציאה) כאירועים נפרדים.
- **API פתוח** בלי הרשמה (JSON, CORS פתוח, מפרט OpenAPI).
- **שקיפות מקורות**: כל אירוע מציג מאילו מקורות הוא נאסף, עם קישור לכל אחד.

## איך זה עובד

1. כל 3 שעות השרת סורק את מקורות המידע (ראו `src/sources/`).
2. רשומות שמתארות את אותו אירוע (אותו יום, בהפרש של עד שעתיים וחצי) ממוזגות לאירוע אחד עם רשימת מקורות.
3. לכל אירוע מחושבים סוג, קהל צפוי וחלונות עומס (`src/enrich.js`):
   - **עומס הגעה**: משעתיים לפני תחילת האירוע ועד רבע שעה אחריה.
   - **עומס יציאה**: מרבע שעה לפני הסיום המשוער ועד שעה ורבע אחריו.
   - **קהל צפוי**: הערכה לפי סוג האירוע וקיבולת ההיכל (כ-11,000). משחקי צמרת ודרבי מסומנים כמלאים.
4. מקור שנכשל שומר את הנתונים התקינים האחרונים שלו, והכשל מוצג בעמוד המקורות.

### למה נוספו טיקטמאסטר והיכלי הספורט

ב-4 בנובמבר 2026 הופיע בוי ג'ורג' בהיכל (Live Nation, במה 360°, כמעט סולד-אאוט), והאתר לא הציג את ההופעה. הכרטיסים נמכרו רק בטיקטמאסטר ישראל, שלא היה מקור. באותו שבוע גם ליאור נרקיס (5.11) והופעה שנייה של בוי ג'ורג' (7.11) נמכרו שם. לוח האירועים של חברת היכלי הספורט, מפעילת ההיכל, הציג את ההופעה, ולכן נוסף כמקור שלא תלוי בחברת הכרטיסים.

המקורות האלה נקראים בשיטה כללית (`src/sources/listing.js`): קודם JSON-LD, אחר כך "כרטיסים" (קישור לאירוע והטקסט של האלמנט שעוטף אותו: כותרת, תאריך בעברית/אנגלית/מספרים, שעה ואולם), ולבסוף דף האירוע עצמו לכרטיסים שחסר בהם מידע. אם אתר משנה מבנה, המקור יחזיר 0 אירועים או ייכשל, וזה יוצג בעמוד המקורות. אירוע שחסר אפשר להוסיף מיד ל-`data/manual-events.json`.

משחקים במחזורים רחוקים מתפרסמים במקורות השונים עם תאריכים זמניים שלא תמיד תואמים (למשל 26, 27 או 28 בדצמבר לאותו משחק). משחק בין אותן קבוצות בטווח של 3 ימים נחשב לאותו משחק, וכשהמקורות לא מסכימים על המועד הוא מסומן "מועד לא סופי".

> בעונת 2026–27 מכבי והפועל תל אביב משחקות את משחקי הבית ביורוליג מחוץ לישראל, ולכן המקור הזה מחזיר כרגע 0 אירועים. הוא יתחיל להציג משחקים ברגע שיחזרו לשחק בהיכל.

רוצים להוסיף מקור? כל מקור הוא מודול עם `id`, `name`, `homepage` ופונקציית `fetch()` שמחזירה רשימת אירועים. לאתרים שמפרסמים JSON-LD מספיק להוסיף שורה ל-`src/sources/index.js` עם `jsonLdSource({...})`, ולאתרי כרטיסים בלי API יש `listingSource({ pages, linkPattern, requireVenueMatch, sitemaps })`.

## API

| נקודת קצה | תיאור |
|---|---|
| `GET /api/events` | אירועים קרובים. פרמטרים: `from`, `to`, `category`, `include_past`, `limit` |
| `GET /api/events/{id}` | אירוע בודד |
| `GET /api/next` | האירוע הבא או זה שמתקיים עכשיו |
| `GET /api/sources` | מקורות ומצב הסריקה האחרונה |
| `GET /api/categories` | סוגי אירועים |
| `GET /calendar.ics` | פיד iCal (`?traffic=1` לחלונות עומס, `?category=sports` לסינון) |
| `GET /api/openapi.json` | מפרט OpenAPI 3 |

הגבלת קצב: 120 בקשות לדקה לכתובת IP.

## הרצה מקומית

```bash
npm install
npm test
npm start   # http://localhost:3000
```

בלי `DATABASE_URL` הנתונים נשמרים בזיכרון. עם `DATABASE_URL` (Postgres) הם נשמרים בטבלאות `source_events` ו-`source_runs`, שנוצרות אוטומטית.

### משתני סביבה

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `PORT` / `XHOST_HTTP_PORT` | `3000` | פורט השרת |
| `DATABASE_URL` | — | Postgres (לא חובה) |
| `REFRESH_MINUTES` | `180` | תדירות הסריקה |
| `BASE_URL` | — | הכתובת הציבורית, לקישורים בתוך היומן |
| `ADMIN_TOKEN` | — | אם מוגדר, מאפשר `POST /api/refresh` עם `Authorization: Bearer <token>` |
| `GA_MEASUREMENT_ID` | — | מזהה Google Analytics 4 (`G-XXXXXXX`). בלעדיו האנליטיקס כבוי |

## פריסה

האתר רץ על [xhostd](https://xhostd.com): `install.sh` מתקין תלויות ו-`launch.sh` מפעיל את השרת. xhostd מזריק `XHOST_HTTP_PORT` ו-`DATABASE_URL`.

## אבטחה

- אין הרשמה ואין איסוף מידע אישי. כשמוגדר `GA_MEASUREMENT_ID`, האתר טוען Google Analytics 4 למדידת שימוש אנונימית (צפיות בעמודים, מעבר בין תצוגות, הוספה ליומן). GA משתמש בעוגיות משלו. מדיניות הפרטיות בכתובת `/privacy` והצהרת הנגישות בכתובת `/accessibility`.
- כל הטקסט שמגיע ממקורות חיצוניים מנוקה מ-HTML ומוצג דרך `textContent`. קישורים מותרים רק ב-`http(s)`.
- Content-Security-Policy קשיח (ללא סקריפטים inline; הסקריפט החיצוני היחיד הוא של Google Analytics, ורק כשהוא מוגדר), `X-Frame-Options: DENY`, `nosniff`.
- הורדות מהמקורות מוגבלות בזמן (25 שניות) ובגודל (8MB).
- נקודת הקצה היחידה שכותבת (`POST /api/refresh`) כבויה אם לא הוגדר `ADMIN_TOKEN`, וההשוואה שלה עמידה ל-timing attacks.

## הסתייגות

הנתונים נאספים אוטומטית ממקורות ציבוריים ועלולים להיות חלקיים או לא מעודכנים. שעות העומס וגודל הקהל הם הערכה בלבד. לפני אירוע חשוב, בדקו מול המקור.
