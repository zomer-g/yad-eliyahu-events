סנכרון ליומן

הוסיפו את היומן לגוגל קלנדר והוא יתעדכן אוטומטית (גוגל מרעננת יומנים חיצוניים כל כמה שעות). אפשר להשתמש באותה כתובת גם ב-Outlook וביומן של אפל.

הוספה לגוגל קלנדר פתיחה באפליקציית יומן

נקודות קצה

קריאה בלבד, עד 120 בקשות לדקה לכתובת IP.

  • GET /api/events · אירועים קרובים. פרמטרים: from, to (ISO 8601), category (sports / concert / show / conference / other), include_past=true, limit (עד 500).
  • GET /api/events/{id} · אירוע בודד.
  • GET /api/next · האירוע הבא (או זה שמתקיים עכשיו).
  • GET /api/sources · מקורות המידע ומצב הסריקה האחרונה.
  • GET /api/categories · סוגי אירועים.
  • GET /calendar.ics · יומן iCal. ?traffic=1 מוסיף חלונות עומס; ?category=sports מסנן.
  • GET /api/openapi.json · מפרט OpenAPI 3.

Example

curl "https://<host>/api/events?category=sports&from=2026-11-01&to=2026-12-31"

Each event includes traffic.level (low/medium/high), traffic.expectedAttendance, traffic.arrivalWindow, traffic.departureWindow, confirmed, timeTbd and the list of sources it was found in. Attendance and traffic windows are estimates.
